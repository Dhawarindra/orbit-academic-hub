# ORBIT — Requirements Traceability Matrix

Versi: **v0.2.1 DDP1 Errata** · Tanggal: **18 November 2026 (Asia/Jakarta)** · Owner: **Product Lead** · Status: untuk review manusia.


## Cakupan dan penggunaan

Setiap FR memiliki AC dan test primer satu-ke-satu. Business rules dipetakan ke AC/test perilaku terkait; mapping berarti lokasi verifikasi, bukan bukti semua cabang sudah lolos uji. NFR punya AC/test tersendiri bernomor 101+. Cross-module scenarios tercatat setelah matriks. Seluruh test implementasi belum dijalankan karena paket ini hanya dokumentasi.

Jumlah: **143 FR**, **102 BR**, **39 NFR**; **182 AC** dan test primer. P0 pada NFR adalah gate untuk fungsi yang diaktifkan, tidak memaksa pembangunan P1/P2.

Tidak ada FR P0 aktif tanpa test primer; tidak ada data nyata tanpa owner/privacy gate; tidak ada penggunaan hasil scenario sebagai actual; tidak ada policy official claim tanpa source binding; tidak ada source hidden yang tetap muncul lewat search/cache. Review BR harus memastikan semua cabang algoritma penting mendapat fixture tambahan ketika implementasi dimulai.
